What is servlet: It is an API which is set of java interfaces and classes that enables java developers to create server side web component or java web application. It runs on web server or application server and handle HTTP client request. It is part of java EE or Jakarta EE. It is platform independent

What is JSP: It stands for java or Jakarta server pages. It is server side technology which is used to create dynamic web pages by embedding java code into HTML. With the help of JSP we can write java code inside html pages for dynamic behaviour it is part of java EE or Jakarta EE which works of top on servlet technology.

	To achieve session with cookies we use cookies classad
advantages: it is simple to use 
disadvantage: it's size is limited, it can be disable by users, it is less secure

2. URL rewriting: we use reponse.sendredirect("pageName;id=123") 
advantage: it works even cookies are disables
disadvantages: it is less secure because session id visible in URL

3. Hidde From fields: we use <input type="hidden" name = "", value"123"/>
advantagees: it is simple to use.
disadvantages : it works only with HTML forms and it is not secure.

4. HTTPSession: it is interace which is present in jakarta.servlet package. it has multiple methods to achieve session. in this data is stored on the server and browser as well and each usr get the unique session id while performing request from client to server.
advantages: it is more secure and no size limitatiions 
disadvantages: it uses server memory

##Hibernate-JPA: 
#What is hibernate: It is an object relational mapping(ORM) framework for java which is used to communicate from java appliation to database.
it acts as a bridge betweeen your java code and database 
it used to simplefy database intraction from java app to database

#Why hibernate is used : When working with database developer has to wright sql queries and convert resultset into java objects manually and handle connections, transactions and exception manually but in hibernate all the above things will be automates no need to write manually 

Note : hiberbate generate 80% query automatically but in some senario developer has to write 20% query manually.

#How hibernate works:
1. java classes(entity class) are automatically converted to database tables so no need create database manually 
2. Entity fields(attributes) automatically conveted to database table columns 
3. java classes objects are automatically saved as a database table rows. hiernate generate sql query behind the secene
	for example: 
		class Product{ ----> Entity class will be converted into table in database
			id;
			name;
			color;
			price
		}
		
#Key features of hibernate: it is database independent framework. it automatic create the tables. it supports HQL(hibernate query language) that is object oriented query language and it is a alternative to SQL. It also supports JPQL with JPA(Jakarta persistance query language) it is also alternative of SQL. It manages the transaction with database

#advantages of hibernate: It reduces SQL errors. it is easy to switch between multiple database it provide faster development with less code

#Where hibernate is used: it enterprise java application and all kind of web applications. In modern era it is used in spring based application.

#Hibernate vs JDBC 
					JDBC																		Hibernate
	It is low level API 													it is highlevel ORM framework build on top of JDBC
	Developers write SQL query manually									But in hibernate 80% query generated automatically .
	Developers handle Connection, Statement, Statements, ResultSet.		It handle connection, transaction and mapping internally.
	JDBC  is faster  for simple application								Hibernate is better for complex application	
	
#What is JPA: It stands for java or jakarta persistance API. It is Java specification whichi used to manage, store and retrive data between java objecs and relational databases. JPA defines rules for ORM(Hibernate framework), but it does not provide implimentation.
#What is Use of JPA: 
	it provide specification to ORM tools to map java classes to database tables and manages object persistance. jPA defines annotations and APIs to provide rules to ORM. JPA itself cannot work alone it needs a provider such as
		. Hibernate(most populer ORM)
		. EclipseLink																																																							
		. OpenJPA																																																							
		. MyBeti																																																							
#Advantages of JPA: It can integrate well with spring framework. it provides cleaner and portabel code and easy switch implementation.
	
#Difference between JPA and hibernate
					JPA													Hibernate
	JPA is specification define by java 						Hibernate is a ORM Framework 
	It defines rules and APIs for ORM						It is JPA implementation
	It does not provide implementation						It provide extra features beyond JPA 
	It needs a provider to work								Can be used with or without JPA
