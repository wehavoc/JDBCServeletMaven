What is servlet: It is an API which is set of java interfaces and classes that enables java developers to create server side web component or java web application. It runs on web server or application server and handle HTTP client request. It is part of java EE or Jakarta EE. It is platform independent

What is JSP: It stands for java or Jakarta server pages. It is server side technology which is used to create dynamic web pages by embedding java code into HTML. With the help of JSP we can write java code inside html pages for dynamic behaviour it is part of java EE or Jakarta EE which works of top on servlet technology.

JSP animates(Tags): It provides several tags to write java code inside HTML pages 
Scriptlet Tag
	<%   
		//here we can write java code
	%>
Scriplet Tag: Inside this tag we can write java variable declaration, method call statement, object creations, looping statements, decision statements etc.
example: 
	<%
		int a = 10;
		out.print(a);	// it will print in Web page
		System.out.println(a);	// It will print in console 
	%>
2. Expression Tag: it is used print output on the browser and it is equivalent to out.print statement. we cannot write expression tag inside the scriptlet tag.
	<% =
 		//here we can write java code
 	%>
3. Declared Tag: this is used to declare method and variable.
example: 
	<%! public int getFactorialNumber(int a) {
		int fact = 1;
        	for(int i = 1; i <= a; i++) {
            		fact = fact * i;
        	}
        	return fact;
	}%>

Session is Servlet API : In servlet API, a session is way to store user specific data across multiple HTTP request, HTTP request static call the server does not automatically remember a user between request. session solve this by keeping data associated with a particular user for period of time. 
a session typically store information like 1.loggin status 2. user preferences. 3. Shopping card data.

## Different ways to achieve session tracking: 
1. Cookies: Cookies store the data on client browser. Server send the cookies to the browser and browser stores and send it back with every request to the servver so server can recognise every request coming from client to server.
	To achieve session with cookies we use cookies classad
advantages: it is simple to use 
disadvantage: it's size is limited, it can be disable by users, it is less secure

2. URL rewriting: we use reponse.sendredirect("pageName;id=123") 
advantage: it works even cookies are disables
disadvantages: it is less secure because session id visible in URL

3. Hidde From fields: we use <input type="hidden" name = "", value"123"/>
advantagees: it is simple to use.
disadvantages : it works only with HTML forms and it is not secure.

4. HTTPSession: it is interace which is present in jakarta.servlet package. it has multiple methods to achieve session. in this data is stored on the server and browser as well and each usr get the unique session id while performing request from client to server.
advantages: it is more secure and no size limitatiions 
disadvantages: it uses server memory
How to achive this: 
	Step 1: get the object of HTTP session and store data inside the session as a key and value pair
		doPost(HttpServletRequest req, HttpServletResponse res)
		HttpSession s = req.geSession()
		s.setAttribute("userId", 123)
	Step 2: Retrieving data from session to do secure request and response
		String s = (Strin)s.getAttribute("userid")
	Step 3: Removing session data 
		how to remove session -> s.removeAttribute(userId);
	Step 4: Ending the session or invalid a session
		How to do this -> s.invalidate()
		It destroyes the session and removes all stored data. it is commanly used in logout process

## Session Timeout: here session automatically expires after inactive time we can set default timeout in web.xml or with the help of inbuilt method(s.setMaxInActiveInterval(time is second))
